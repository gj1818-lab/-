# 27SS 출고계획 조율

27SS 시즌 출고 지연 리스크를 조기에 파악하기 위한 **출고계획 조율 트래커** 프로젝트.

## 파일 구성

- `GOAL.md` — 목표와 완료 기준 (작업 시작 전 필독)
- `PROGRESS.md` — Phase별 진행 상황 + 검증 로그
- `CLAUDE.md` — 이 프로젝트의 Claude Code 규칙
- `docs/DESIGN_GUIDE.md` — PPTX 슬라이드 디자인 가이드 (보고 자료 제작 시 적용)
- `docs/MAC_SETUP_GUIDE.md` — 팀 Mac 셋업 가이드
- `data/` — 입력 데이터 (출고계획 CSV 등)
- `output/` — 결과물 (트래커, 확정본, 보고 자료)
