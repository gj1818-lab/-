# New Project Scaffolding (팀 표준 자동 적용)

새 프로젝트 폴더를 만들고, 팀 표준 문서 2종을 프로젝트 안에 복사한 뒤, Claude Code가 앞으로 이 표준을 자동으로 따르도록 `CLAUDE.md`를 생성하는 스킬이다.

## 인자(Arguments)

- `/new-project <프로젝트명>` 형태로 프로젝트명이 오면 그대로 사용한다.
- 프로젝트명이 없으면 사용자에게 프로젝트명(폴더명)을 물어본다.
- 현재 디렉토리 안에 새 폴더를 만드는 것이 기본이다. 사용자가 "현재 폴더에 세팅해줘"라고 하면 폴더를 새로 만들지 않고 현재 디렉토리에 바로 세팅한다.

## 수행 절차

1. **프로젝트 폴더 생성**: `<프로젝트명>/` 폴더를 만든다 (현재 폴더 세팅 모드면 생략).

2. **표준 문서 복사**: 이 스킬 폴더의 `references/` 안에 있는 두 파일을 프로젝트의 `docs/` 폴더로 복사한다.
   - `references/design-guide.md` → `docs/DESIGN_GUIDE.md` (PPTX 슬라이드 디자인 가이드)
   - `references/mac-setup-guide.md` → `docs/MAC_SETUP_GUIDE.md` (팀 Mac 셋업 가이드)

3. **CLAUDE.md 생성**: 프로젝트 루트에 아래 내용을 담은 `CLAUDE.md`를 만든다. 프로젝트명과 한 줄 설명은 실제 값으로 채운다.

   ```markdown
   # <프로젝트명>

   <프로젝트 한 줄 설명>

   ## 팀 표준 (반드시 준수)

   ### 슬라이드/PPTX 작업 규칙
   - 이 프로젝트에서 PPTX, 슬라이드, 프레젠테이션, 보고서 덱을 만들 때는
     **반드시 `docs/DESIGN_GUIDE.md`를 먼저 읽고** 그 안의 컬러 토큰, 타이포그래피,
     레이아웃 레시피, 컴포넌트 규칙을 그대로 적용한다.
   - 핵심 요약: 16:9 (13.319 x 7.5 in), 기본 폰트 Pretendard(대체: 맑은 고딕,
     Apple SD Gothic Neo, Noto Sans KR), 브랜드 컬러 `brand-green #2C5F2D`,
     좌우 여백 0.5 in, 상단 헤더바 + 하단 페이지 푸터바 반복.
   - 표지는 brand-green 전체 배경, 본문은 흰 배경 + 도형 직접 배치 방식.

   ### 개발 환경
   - 팀 표준 개발 환경 설치/온보딩은 `docs/MAC_SETUP_GUIDE.md`를 따른다.
   - 신규 팀원 온보딩 질문이 나오면 이 문서를 안내한다.

   ## 프로젝트 구조

   - `docs/` — 팀 표준 문서 및 프로젝트 문서
   ```

4. **README.md 생성**: 프로젝트명, 한 줄 설명, `docs/` 안내가 담긴 간단한 README를 만든다.

5. **git 초기화**: 프로젝트 폴더가 git 저장소가 아니면 `git init` 후 첫 커밋(`chore: scaffold project with team standards`)을 만든다. 현재 폴더 세팅 모드에서 이미 git 저장소라면 커밋은 사용자에게 확인 후 진행한다.

6. **완료 보고**: 만들어진 파일 목록과, "이제 이 프로젝트에서 슬라이드 작업을 요청하면 디자인 가이드가 자동 적용됩니다"라는 안내를 한국어로 짧게 출력한다.

## 주의사항

- `references/` 안의 원본 표준 문서는 절대 수정하지 않는다. 프로젝트에는 항상 **복사본**을 넣는다.
- 사용자가 특정 문서만 원하면(예: "디자인 가이드만") 해당 문서만 복사하고 CLAUDE.md도 그에 맞게 줄인다.
- 기존 파일을 덮어쓰게 되는 경우(이미 CLAUDE.md나 docs/가 있는 경우) 덮어쓰기 전에 반드시 사용자에게 확인한다.
