# New Project Scaffolding (팀 표준 자동 적용)

새 프로젝트 폴더를 만들고, 팀 표준 워크플로우 파일 3종(CLAUDE.md / GOAL.md / PROGRESS.md)과 표준 문서 2종(디자인 가이드 / Mac 셋업 가이드)을 세팅하는 스킬이다.

핵심 철학: **GOAL.md에 목표와 완료 기준을 먼저 정의하고, 작은 Phase 단위로 진행하며, 검증 결과를 PROGRESS.md에 기록한다. 검증 없는 진행은 진행이 아니다.**

## 인자(Arguments)

- `/new-project <프로젝트명>` 형태로 프로젝트명이 오면 그대로 사용한다.
- 프로젝트명이 없으면 사용자에게 프로젝트명(폴더명)을 물어본다.
- 기본은 현재 디렉토리 안에 새 폴더 생성. 사용자가 "현재 폴더에 세팅해줘"라고 하면 폴더를 새로 만들지 않고 현재 위치에 바로 세팅한다.

## 수행 절차

1. **프로젝트 폴더 생성**: `<프로젝트명>/` 폴더를 만든다 (현재 폴더 세팅 모드면 생략).

2. **GOAL.md 인터뷰 (가장 중요)**: 이 스킬 폴더의 `templates/GOAL.md`를 프로젝트 루트로 복사하기 전에, 사용자에게 아래 항목을 간단히 물어본다 (AskUserQuestion 또는 대화로).
   - 프로젝트 목적 (왜 필요한가, 어떤 실무 문제를 해결하는가)
   - 목표 (구체적으로 무엇을 만드는가)
   - 완료 기준 (무엇이 되면 "끝"인가 — 체크 가능한 형태로)

   답을 받으면 `GOAL.md`의 해당 섹션(1. 목적, 2. 목표, 4. 완료 기준)을 채워서 생성한다. 사용자가 "나중에 채울게"라고 하면 템플릿 그대로 복사한다. 나머지 섹션(사용자/범위 밖/데이터/기술 방향/Phase 계획)은 사용자가 준 정보가 있으면 채우고, 없으면 placeholder로 둔다.

3. **PROGRESS.md 생성**: `templates/PROGRESS.md`를 프로젝트 루트로 복사한다. `[프로젝트 이름]`을 실제 프로젝트명으로, `마지막 업데이트`를 오늘 날짜로 바꾼다. GOAL.md에서 Phase 계획이 정해졌으면 단계별 로그의 Phase 이름도 채운다.

4. **CLAUDE.md 생성**: `templates/CLAUDE.md`를 프로젝트 루트로 복사한다.
   - `[프로젝트 이름]`을 실제 프로젝트명으로 바꾼다.
   - "이 프로젝트는 무엇인가" 섹션을 GOAL.md 내용의 한 문단 요약으로 채운다.
   - 기술 스택 등 사용자가 알려준 정보가 있으면 함께 채우고, 모르는 항목은 placeholder로 둔다.

5. **표준 문서 복사**: `references/`의 두 파일을 프로젝트의 `docs/` 폴더로 복사한다.
   - `references/design-guide.md` → `docs/DESIGN_GUIDE.md` (PPTX 슬라이드 디자인 가이드)
   - `references/mac-setup-guide.md` → `docs/MAC_SETUP_GUIDE.md` (팀 Mac 셋업 가이드)

6. **README.md 생성**: 프로젝트명, 한 줄 설명, 파일 구성 안내가 담긴 간단한 README를 만든다.

7. **git 초기화**: git 저장소가 아니면 `git init` 후 첫 커밋(`chore: scaffold project with team standards`)을 만든다. 이미 git 저장소라면 커밋은 사용자에게 확인 후 진행한다.

8. **완료 보고**: 만들어진 파일 목록과 함께, 다음 단계를 안내한다:
   - GOAL.md에 비어 있는 항목이 있으면 채우라고 안내
   - "이후 이 프로젝트에서 작업하면 GOAL.md/PROGRESS.md 기반 Phase 진행 방식과 디자인 가이드가 자동 적용됩니다"

## 스캐폴딩 이후의 작업 원칙 (CLAUDE.md에 이미 반영됨)

- 작업 시작 전 GOAL.md와 PROGRESS.md를 먼저 읽는다.
- 코드 작성 전 구조·로직·데이터부터 확인받는다.
- 작은 Phase 단위로 진행하고, 각 Phase 끝에서 사람 승인을 받는다.
- 진행 상황과 **검증 결과**를 PROGRESS.md에 기록한다.
- 슬라이드/PPTX 작업은 docs/DESIGN_GUIDE.md를 따른다.

## 주의사항

- `templates/`와 `references/` 안의 원본은 절대 수정하지 않는다. 프로젝트에는 항상 **복사본**을 넣는다.
- 기존 파일을 덮어쓰게 되는 경우(이미 CLAUDE.md, GOAL.md 등이 있는 경우) 덮어쓰기 전에 반드시 사용자에게 확인한다.
- 사용자가 특정 문서만 원하면 해당 문서만 세팅한다.
