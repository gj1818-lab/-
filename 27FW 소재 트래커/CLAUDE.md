## 이 프로젝트만의 규칙

### 27SS에서 확정되어 이어받는 로직 (변경 시 담당자 확인)

- 출고일(주차) 원천 = **생진테 출고예정주차**. 주차→날짜: 1주=1일/2주=8일/3주=15일/4주=22일
- 리드타임: 출고예정일 −2주 = 제품입고 시점 → 입고 −90일 = 소재입고 마감 (기준정보 탭에서 조정 가능하게)
- 작지발행 = 전산 일매(디자인담당 결재, EDW R열), 사양확정 = EDW U열. 공정 순서: 일매 → 사양확정
- **IMPORTRANGE 빈 셀 오집계 방지: COUNTIFS 조건은 반드시 `"?*"`** (`"<>"` 금지 — 27SS에서 사양확정 395/424 과다 표시 버그의 원인)
- 비수기 = KS_비수기 선정.xlsx 해당 시즌 탭 N열 'O' (품번+컬러 단위일 수 있으니 앞 10자로 스타일 정규화)
- 소재DB 조인 시 진행구분 'Drop' 제외, 품번 뒤 공백 주의 → `품번&"*"` 와일드카드 매칭
- 피싱 스타일(품번 8-시작, BLUE 라벨)은 일반과 분리해 별도 표기 (27FW 기획 리스트에는 현재 0건)
- 정렬: 시즌코드 → 비수기 선정 → 나머지 (27SS: S → 비수기 → M→X 순이었음, FW 순서는 확정 필요)

### 27FW 확정 사항 (2026-09-07 담당자 확인)

- 연도 매핑: 출고 주차 **전부 2027년**
- 공장휴무 보정: 생산국(베트남/인도네시아/미얀마) 기준 — **미얀마 띤쨘(2027-04-13~16 고정) + 인도네시아 르바란(Eid 2027-03-10 전후 ~1주)**. 중국 명절 미반영. 보정 기간 최종 확정 대기
- 시즌코드: **A(가을)+W(겨울)+X(사계절) 전부** — 435 스타일
- 리드타임: 출고 −2주 = 제품입고 → **입고 −100일 = 소재마감** (27SS는 90일. 기준정보 탭에서 조정 가능하게)
- 출고예정주차: 기획 리스트에 미입력 상태 — 담당자 재공유 대기 (수령 전 빌드 금지)

### 기술 스택

- Python (openpyxl) — xlsx 트래커 빌드, `../27SS 출고계획 조율/scripts/` 재사용
- 구글시트 수식 (ARRAYFORMULA, IMPORTRANGE, MAP+COUNTIFS, MAXIFS) — 운영판
- **Drive 커넥터는 셀 쓰기 불가** → 시트 수정은 ① CSV(text/csv) 업로드→구글시트 자동 변환(수식 파싱됨, 그리드 열 수는 헤더 필드 수로 고정되니 참조 최대 열까지 패딩) ② 붙여넣기 블록 전달
