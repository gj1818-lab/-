# 27FW 소재 트래커

27FW 시즌 스타일별 출고예정일에서 소재입고 마감일을 역산해 납기위험을 조기 판정하는 소재일정 트래커. `27SS 출고계획 조율` 프로젝트의 후속 시즌 버전.

## 파일 구성

| 파일/폴더 | 내용 |
|-----------|------|
| `GOAL.md` | 목표·완료 기준·확인 대기 항목 |
| `PROGRESS.md` | 진행 상황과 검증 로그 |
| `CLAUDE.md` | 프로젝트 규칙 (27SS 승계 로직 포함) |
| `data/` | 입력 데이터 |
| `scripts/` | 빌드 스크립트 |
| `docs/` | 팀 표준 문서 |
| `output/` | 트래커·배포 산출물 |

## 진행 방식

GOAL.md → 작은 Phase 단위 진행 → 각 Phase 끝 사람 승인 → PROGRESS.md에 검증 결과 기록.
